### Hi, I'm Andrews (Andrey Bogatyrev)

Backend development is my hobby. I write **Python**, mostly **Django** and **Flask**. I build small
web apps by myself: database, API, frontend and deployment on my own VPS.

I try to finish what I start. It is not only about code: a project should be usable by normal
people, for free. That is why TaskMan and Lex are published on RuStore and AppGallery.

**Projects**

- **[Lex](https://github.com/Onoiro/lex)** - a translator and vocabulary trainer with spaced
  repetition. It works offline and keeps data on the device. The backend is a small FastAPI proxy
  for translation and text-to-speech. The frontend is React, and there are Android and desktop
  builds. Live at [lextr.ru](https://lextr.ru).
- **[SportMemo](https://github.com/Onoiro/sportmemo)** - a public archive of sports photos with
  attribution. Django, PostgreSQL, file storage in S3, background tasks with Celery, search and
  moderation.
- **[TaskMan](https://github.com/Onoiro/TaskMan)** - a task manager for small teams and families.
  Django and Docker Compose, CI with deploy to staging, interface in 8 languages.
- **[Radio Andrews](https://github.com/Onoiro/radio_andrews)** - an internet radio station on Flask,
  Icecast and Liquidsoap. It plays tracks I wrote myself: the rap lyrics are mine, the music was
  made with Suno.

**Tools I use**

- Python, Django, Flask, FastAPI, SQLAlchemy
- PostgreSQL, SQLite, Redis, MinIO (S3)
- Docker Compose, Nginx, GitHub Actions, Linux VPS
- pytest, ruff, Vitest, SonarQube, Rollbar. CI runs on every project
- HTML, CSS, Bootstrap, htmx, a little JavaScript
